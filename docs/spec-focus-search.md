# 仕様書: フォーカスモード + 検索フィルタ

## 概要

グラフのノード数が増えたときの視認性改善として、以下の2機能を実装する。

1. **フォーカスモード** — ノードを選択したとき、関連するノードのみを表示して残りを非表示にする
2. **検索フィルタ** — クラス名でノードを絞り込む。検索結果から1ノードを選ぶとフォーカスモードへ移行する

---

## 1. フォーカスモード

### 1-1. 起動

- グラフ上のノードをクリックする
- 選択ノードから双方向BFSで到達可能な全ノードを算出し、それらのみを表示する
- 到達不能なノードは完全に非表示（dimではなく非表示）にする

「双方向」とは、エッジの向きを無視して隣接ノードをたどることを意味する。  
例: `OrderService → AccountService` というエッジがある場合、AccountService を選択しても OrderService は関連ノードとして表示される。

### 1-2. 折りたたみ

フォーカスモード起動時は全到達ノードを表示するが、ノード数が多い場合は手動で絞り込める。

- ツールバー（またはステータスバー）に **「折りたたむ」** ボタンを表示する
- クリックすると、表示ノードをフォーカスルートの **1ホップ隣接のみ** に縮小する
- 非表示になった隣接先を持つ境界ノードには **`+N`** バッジ（Nは隠れているノード数）を表示する

### 1-3. 展開

- `+N` バッジをクリックすると、そのノードの直接隣接ノードを **1ホップ分だけ** 表示に追加する
- バッジクリックを繰り返すことで、任意の深さまで段階的に探索できる

### 1-4. 終了

- ESCキーを押す、または背景（Canvas）をクリックする
- 全ノードが再び表示される

### 1-5. ステータス表示

フォーカスモード中はステータスバーに以下を表示する：

```
フォーカス: AccountService  ×N ノード表示中  [折りたたむ]  ESCで解除
```

---

## 2. 検索フィルタ

### 2-1. 検索ボックス

- ツールバー（画面上部）に検索入力ボックスを配置する
- 入力するとリアルタイムでクラス名（`GraphNode.label`）をインクリメンタルフィルタする
- 一致するノードのみを表示し、残りは非表示にする
- 入力をクリアすると全表示に戻る

### 2-2. 検索結果からのフォーカス移行

- 検索中にノードをクリックすると **フォーカスモード** に移行する
- 検索クエリと一致しないノードでも、フォーカスルートに関連していれば表示する
- 検索ボックスの入力はフォーカスモード中も保持するが、表示ノード集合はフォーカスモードの算出結果を優先する

---

## 3. 内部状態モデル

`ViewState`（Zustandストア）に以下を追加する：

```typescript
focusRootId: string | null;       // フォーカス中のノードID。nullはフォーカスモード未起動
visibleInFocusIds: Set<string>;   // フォーカスモード中に表示するノードIDの集合
searchQuery: string;              // 検索ボックスの入力値
```

### ノード表示判定ロジック

```
フォーカスモード中 (focusRootId !== null):
  表示 ← visibleInFocusIds に含まれるノード

検索モード中 (searchQuery !== '' && focusRootId === null):
  表示 ← label が searchQuery を含むノード

通常モード:
  表示 ← 既存フィルタ (hideTestClasses / hideManagedPackages) を適用したノード
```

### `visibleInFocusIds` の算出

```
起動時:
  BFS(双方向) でフォーカスルートから全到達ノードを算出 → visibleInFocusIds に設定

折りたたみ時:
  visibleInFocusIds = {focusRootId} ∪ {focusRootId の直接隣接ノード}

バッジクリック時 (対象ノード = clickedNode):
  visibleInFocusIds += clickedNode の直接隣接ノード
```
